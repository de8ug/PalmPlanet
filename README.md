# 掌心星球 · PalmPlanet

**用双手探索真实的地球。**

一个面向亲子探索的浏览器地球：搜索真实城市、测量两地距离、找到地球另一面，并观察真实地震记录。摄像头手势是可选操作方式，鼠标始终可用。

## 运行

需要 Node.js 22.12+（推荐 22 LTS）。

```sh
npm ci
npm run dev
```

打开终端显示的 localhost 地址。不要直接双击 `index.html`。公共数据快照和手势模型已经包含在仓库里，首次启动不需要申请地图账号或密钥。构建时会从已安装依赖复制 Cesium 和 MediaPipe 运行资源到本机。

```sh
npm test
npm run build
npm run preview
```

`dist/` 可以放到普通静态托管服务的根目录或子目录。当前只同步源码，没有自动发布线上站点。

## 第一版能做什么

- **自由探索**：旋转、缩放、点击地球选点；搜索 34,191 条 GeoNames 城市记录，支持中英文及部分别名。
- **量一量**：依次选择 A、B，按 WGS84 椭球计算地表最短距离，绘制同一条测地线。
- **看对面**：计算对跖点，用 Natural Earth 陆地边界判断海陆，查找城市库中较近的城市。
- **找地震**：按需读取 USGS 最近七天 M2.5+ 记录，按震级筛选，查看时间、震级、深度和原始记录。失败时读取明确标注日期的真实快照。
- **切换图层**：本地 Natural Earth II 概览底图、在线 OpenStreetMap 街道、可选日期的 NASA MODIS Terra 真彩色卫星观测。
- **可选手势**：单手捏住移动来转动，双手捏住拉开/靠拢来缩放，短暂捏合后松开来选点。失去手部跟踪时停止操作。

## 数据与精度

详见 [DATA_SOURCES.md](DATA_SOURCES.md)、[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和 `public/data/manifest.json`。

地表距离不是道路里程；城市坐标代表参考点。海陆边界经过简化，近岸、小岛及内陆水体可能误判。概览底图放大后不会出现真实街道，应切换街道图层；NASA 图层也不是任意时刻的实时高清画面。

第一版采用椭球表面，尚未接入三维高程、板块、地球内部剖面或天文图层。地震记录有延迟、修订及地区覆盖差异；光点大小仅作视觉区分。

## 摄像头与隐私

摄像头只有点击“开启手势”后才会请求权限。图像在浏览器本机由 MediaPipe 处理，不录制、不上传，不申请麦克风或定位权限。关闭手势会停止摄像头轨道。需要 localhost 或 HTTPS 及支持 WebGL 的浏览器；可通过鼠标使用全部地理功能。

在线地图与地震服务会收到正常的网络请求，例如图块范围和日期。应用无账号、无分析埋点，也不保存位置搜索历史。

## 更新公开数据

```sh
npm run data:refresh
```

需要联网、`curl` 和 `unzip`。默认复用已有城市、海陆和手势模型，更新地震快照及来源清单。使用 `PALMPLANET_REFRESH_CITIES=1`、`PALMPLANET_REFRESH_LAND=1` 或 `PALMPLANET_REFRESH_MODEL=1` 强制更新对应内容。提交前运行测试，核对来源、日期与授权。

## 本次探索

这个独立实验探索的是：真实坐标如何连接地点、距离和地球对面，以及真实地震记录如何落在三维地球上。让孩子自己选地点、先猜结果，再通过操作验证。项目没有包含儿童身份、照片、声音或家庭位置。

## 城市探索与全息背景（2026-10-30）

选中城市后可阅读简介和景点卡片，点击景点会切到在线街道地图并飞到其坐标。北京、上海、东京、伦敦、悉尼、巴黎目前提供本地资料；其他城市可主动联网查附近的百科地点。百科网络访问受环境影响，无资料时会明确提示。地图点击保留原坐标，附近城市仅作参考。

画面上方“人物画面”可选择“小窗口”或“全息背景”。开启手势并允许摄像头后，背景模式将同一条本机视频流放到地球后方，地球以半透明效果悬浮，滑杆可调地球不透明度。切回小窗不另开摄像头，关闭手势会清理两处视频显示。本版是视频叠加，不包含人物抠像、VR 设备支持或空间深度跟踪。
